# OI 练习助手

面向算法竞赛学习者的离线练习工具，涵盖 94 个算法专题、500+ 道洛谷真题，所有题目数据本地缓存、即开即用。

## 功能特点

- **94 个算法章节** — 从 DFS/BFS 到 LCT、多项式，系统覆盖竞赛核心知识体系
- **阶梯难度** — 每章按 模板 → 绿(普及+) → 青(提高+) → 蓝(省选) → 紫(NOI) 递进排列
- **完整题目数据** — 题面描述、输入输出格式、样例、数据范围均本地缓存
- **LaTeX 数学渲染** — 所有数学公式自动渲染，无 `$n$` 等原始代码
- **离线可用** — 无需网络连接即可浏览全部题目
- **路径可移植** — 下载到任意目录均可运行

## 快速开始

直接用浏览器打开 `index.html` 即可使用。

如需重新生成题目数据：

```bash
# 安装依赖
pip install curl_cffi python-docx

# 从 .docx 生成题目分配
python build_from_docx.py

# 从洛谷爬取题目详情（需要网络）
python batch_fetch.py

# 更新本地缓存
python update_cache.py
```

## 难度对照

| 标签 | 洛谷颜色 | 难度值 | 说明 |
|------|---------|--------|------|
| 模板 | — | 1 | 各算法最经典的基础题 |
| 绿 | 普及+/提高 | 4 | NOIP 提高组难度 |
| 青 | 提高+/省选- | 5 | 省选入门难度 |
| 蓝 | 省选/NOI- | 6 | 省选核心难度 |
| 紫 | NOI/NOI+ | 7 | 全国赛难度 |

## 关于题目数量

94 个章节 × 每章 10 题 = 940 个题目槽位，由 **502 道不重复的洛谷真题** 填充。

题目之间存在合理的跨章节复用：例如一道"区间 DP + 树形 DP"的题目可能同时出现在 4.3 区间DP 和 4.4 树形DP 两个章节中。平均每道题出现在约 1.9 个章节里，这反映了算法知识点之间自然的交叉关系。
