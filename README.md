# OI 练习助手

> 面向算法竞赛学习者的离线练习工具 —— 94 个算法专题，500+ 道洛谷真题，即开即用。

## 功能特点

- **94 个算法章节** — 涵盖 Part 1~10，从搜索/动态规划到计算几何/多项式，系统覆盖竞赛核心知识体系
- **阶梯难度训练** — 每章 10 题按模板 → 绿(普及+/提高) → 青(提高+/省选-) → 蓝(省选/NOI-) → 紫(NOI/NOI+) 递进排列
- **完整离线缓存** — 题面描述、输入输出格式、样例、数据范围均本地缓存，无需网络即可浏览全部题目
- **LaTeX 数学渲染** — 所有数学公式使用 KaTeX 自动渲染为最终样式
- **代码高亮** — highlight.js 渲染代码块，支持多语言
- **AI 答疑助手** — 内置 AI 对话面板，支持 OpenAI / Claude / Gemini / DeepSeek / GLM / Qwen / Kimi 等 11 家服务商
- **知识地图视图** — 章节以可视化迷宫形式展示，关卡带进度标记
- **进度持久化** — localStorage 保存学习进度和统计数据
- **路径可移植** — 下载到任意目录均可正常运行，不依赖绝对路径

## 快速开始

### 浏览器直接使用

用浏览器打开 `index.html` 即可使用。

### 桌面应用

`build/` 目录下提供了预打包的桌面应用：

| 平台 | 文件 |
|------|------|
| Windows | `build/OI练习助手.exe` |
| Linux | `build/OI练习助手-linux.tar.gz` |

### 重新生成数据（可选）

```bash
# 安装依赖
pip install curl_cffi python-docx

# 从 .docx 文档生成章节题目分配
python build_from_docx.py

# 从洛谷爬取题目详情（需要网络）
python batch_fetch.py

# 更新本地缓存
python update_cache.py
```

## 关于「500 多道题」

94 个章节 × 每章 10 题 = **940 个题目槽位**，由 **502 道不重复的洛谷真题** 填充。

这 502 道题并非随机凑数，而是从 `题目.docx` 中精心筛选的结果：

### 题目质量

| 难度 | 数量 | 占比 |
|------|------|------|
| 紫 (NOI/NOI+) | 91 | 18.1% |
| 蓝 (省选/NOI-) | 79 | 15.7% |
| 青 (提高+/省选-) | 88 | 17.5% |
| 绿 (普及+/提高) | 121 | 24.1% |
| 橙 (普及-) | 67 | 13.3% |
| 红 (入门) | 49 | 9.8% |
| 模板 | 2 | 0.4% |

- **青及以上占比 52.4%**，绿及以上占比 76.5%
- 每章第一题为该算法的经典模板题（如 DFS 章匹配 P1706 全排列问题），后续 9 题严格按绿→青→蓝→紫递增
- 93/94 个章节满 10 题（仅 10.1 模拟退火为 9 题）

### 跨章节复用

算法知识之间存在天然的交叉，同一道题出现在多个章节是合理的教学安排。例如：

- 一道「区间 DP + 树形 DP」的题同时适合在 dp-区间 和 dp-树形 两个章节练习
- 一道「二分 + 贪心」的题同时适合在 二分 和 贪心 两个章节

**复用统计：**

| 出现次数 | 题目数 |
|----------|--------|
| 1 次 (独有) | 358 (71.3%) |
| 2 次 | 69 (13.7%) |
| 3~5 次 | 52 (10.4%) |
| 6 次以上 | 23 (4.6%) |

超过 71% 的题目只在单一章节出现，高度重复（6 次以上）的题目通常是模板题或综合性极强的基础题。

### 如果想扩充

如果需要更多独特的题目，可以扩充 `题目.docx` 文档：为每个章节按「模板 | 绿 | 绿 | 青 | 青 | 青 | 青 | 蓝 | 蓝 | 紫」的格式补充更多洛谷题目 ID，然后重新运行 `build_from_docx.py` 即可。
